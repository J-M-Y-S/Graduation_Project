# 中药片剂溶出度虚拟仿真

本项目基于 Unity 构建中药片剂溶出度测定虚拟仿真系统，规划科普、实操和问答三个学习模块。目前已完成实操模块的核心实验流程与界面交互。

## 操作模块

- 三维操作台：支持机头升降、溶杯加水与倒水、中药片剂投放、温度调节、加热和搅拌等操作。
- 参数设置：可配置 AB/CD 杯转速、取样位置和取样时间点，并对温度、转速与取样顺序进行校验。
- 实验运行：包含运行计时、取样倒计时、按取样点插值调整转速以及完整的开始和停止流程。
- 实时溶出曲线：根据四个溶杯的模拟数据动态更新折线图，并同步显示在仪器旁的外部屏幕上。
- 实验反馈：提供药片消融动画、气泡效果、当前手持药片提示、操作 Toast 和实验参数打印纸条。

## UI 界面

- 点击溶出仪 `MainScreen` 打开半透明参数面板，集中管理运行、取样点、语言和说明等入口。
- 运行界面实时显示 AB/CD 杯转速、温度、运行时间、取样时间与取样倒计时。
- 取样点界面分别配置四个溶杯的取样时间，语言界面支持中英文切换。
- 独立曲线面板通过三维屏幕展示实时溶出曲线，参数面板与曲线面板相互分离。
